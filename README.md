## About

This project is part of the Holberton School curriculum. It demonstrates practical ways to use AI tools like ChatGPT to improve code quality, catch bugs faster, and write better documentation — skills that translate directly into real-world software development.

---

## Learning Objectives

By completing this project, you will be able to:

- Use AI to **identify and fix bugs** in Python and web code
- **Automate repetitive** coding tasks with AI assistance
- **Document code** effectively using AI-generated descriptions, parameters, and return values
- Implement **error handling** to gracefully manage invalid inputs and prevent crashes

## Exercises

### 0. Debugging — Python Factorial
**File:** `debugging/factorial.py`

Identify and correct a bug in iterative Python code that calculates the factorial of a number.

---

### 1. Debugging — Python Arguments
**File:** `debugging/print_arguments.py`

Fix Python code that should print only the command-line arguments passed to the script, excluding the script filename itself.

---

### 2. Debugging — HTML / JavaScript
**File:** `debugging/change_background.html`

Correct an HTML/JavaScript page where clicking a button is supposed to change the background color but fails due to a bug.

---

### 3. Debugging — Python Minesweeper
**File:** `debugging/mines.py`

Fix a Python Minesweeper game to correctly detect when all non-mine cells have been revealed, triggering a win condition.

---

### 4. Documentation — Python Factorial (Recursive)
**File:** `debugging/factorial_recursive.py`

Add proper docstrings to a recursive factorial function, including a description, parameter documentation, and return value.

---

### 5. Error Handling & Documentation — Python Checkbook
**File:** `debugging/checkbook.py`

Add input validation and error handling to a checkbook application so it handles invalid user input gracefully without crashing.

---

### 6. Debugging — Tic Tac Toe
**File:** `debugging/tic.py`

Identify and fix logic errors in a Python Tic Tac Toe game so it plays correctly and accurately determines winners.

## Getting Started

**Clone the repository:**

```bash
git clone https://github.com/XXRV0423/holbertonschool-chatgpt-introduction.git
cd holbertonschool-chatgpt-introduction
```

**Run a Python exercise:**

```bash
python3 debugging/factorial.py
```

**Open the HTML exercise:**

Open `debugging/change_background.html` in any modern web browser.

> **Requirements:** Python 3.x — no external packages needed.
